# Эмулятор командной оболочки

Практическая работа по дисциплине
«Конфигурационное управление».

Вариант №8.

## Общее описание

Проект представляет собой эмулятор командной оболочки
UNIX-подобной операционной системы.

Программа реализована на Python в форме консольного интерфейса.

Разработка выполняется поэтапно. Каждый этап сохраняется
отдельным коммитом в Git-репозитории.

## Этап 1. REPL

На первом этапе реализован минимальный интерактивный
прототип командной оболочки.

Приглашение к вводу формируется на основе имени текущего
пользователя и имени компьютера.

Пример:

```text
username@hostname:~$
```

Поддерживаются команды:

- `ls` — команда-заглушка;
- `cd` — команда-заглушка;
- `exit` — завершение работы эмулятора.

Реализована обработка неизвестных команд и неверных
аргументов.

### Команда ls

На текущем этапе команда выводит переданные ей аргументы.

Пример:

```text
username@hostname:~$ ls folder
ls arguments: ['folder']
```

### Команда cd

На текущем этапе команда выводит переданный аргумент.

Допускается не более одного аргумента.

Пример:

```text
username@hostname:~$ cd documents
cd arguments: ['documents']
```

Пример ошибки:

```text
username@hostname:~$ cd one two
Error: cd accepts no more than one argument.
```

### Команда exit

Команда завершает работу эмулятора.

```text
username@hostname:~$ exit
```

Передача аргументов считается ошибкой:

```text
username@hostname:~$ exit now
Error: exit does not accept arguments.
```

### Неизвестная команда

Пример:

```text
username@hostname:~$ hello
Error: unknown command: hello
```

## Этап 2. Конфигурация

На втором этапе добавлена поддержка параметров
командной строки.

Поддерживаются параметры:

- `--vfs` — путь к физическому расположению VFS;
- `--prompt` — пользовательское приглашение REPL;
- `--script` — путь к стартовому скрипту.

При запуске значения параметров выводятся на экран
для отладки.

### Пользовательское приглашение

Пример:

```powershell
python src\main.py --prompt "shell> "
```

После запуска используется приглашение:

```text
shell>
```

### Путь к VFS

Пример:

```powershell
python src\main.py --vfs vfs\deep.json
```

### Стартовый скрипт

Пример:

```powershell
python src\main.py --script scripts\startup.txt
```

Команды стартового скрипта выполняются последовательно.

Если во время исполнения команды возникает ошибка,
выполнение стартового скрипта прекращается.

После успешного выполнения скрипта эмулятор переходит
в интерактивный режим.

## Этап 3. Виртуальная файловая система

На третьем этапе реализована загрузка виртуальной
файловой системы из JSON-файла.

После загрузки VFS находится только в памяти программы.
Исходный JSON-файл во время работы не изменяется.

### Формат VFS

Корневым элементом является директория.

Пример:

```json
{
  "type": "directory",
  "children": {
    "file.txt": {
      "type": "file",
      "content": "Example"
    }
  }
}
```

Директория содержит словарь `children`.

Обычный файл содержит:

- `type` со значением `file`;
- `content` с содержимым файла.

Для двоичных данных используется представление Base64.

### Тестовые VFS

В каталоге `vfs` находятся:

- `minimal.json` — минимальная пустая VFS;
- `files.json` — VFS с несколькими файлами;
- `deep.json` — VFS с вложенностью более трёх уровней.

### Запуск с VFS

Пример:

```powershell
python src\main.py --vfs vfs\deep.json
```

Совместное использование VFS и стартового скрипта:

```powershell
python src\main.py --vfs vfs\deep.json --script scripts\stage3_startup.txt
```

### Ошибки VFS

Если файл VFS отсутствует, выводится сообщение об ошибке
и эмулятор не запускает REPL.

Некорректный JSON также приводит к сообщению об ошибке.

Перед использованием структура VFS проверяется.

## Основные функции

### `parse_arguments()`

Обрабатывает параметры командной строки.

### `print_configuration(arguments)`

Выводит текущие параметры конфигурации.

### `build_prompt(custom_prompt)`

Создаёт стандартное приглашение на основе данных ОС
или возвращает пользовательское приглашение.

### `parse_command(user_input)`

Разделяет пользовательский ввод на имя команды
и список аргументов.

### `execute_command(command, arguments)`

Определяет введённую команду и вызывает
соответствующий обработчик.

### `run_ls(arguments)`

Реализует заглушку команды `ls`.

### `run_cd(arguments)`

Реализует заглушку команды `cd` и проверяет
количество аргументов.

### `run_exit(arguments)`

Обрабатывает завершение работы эмулятора.

### `run_repl(prompt)`

Запускает интерактивный цикл REPL.

### `run_script(script_path, prompt)`

Выполняет команды из стартового скрипта.

При первой ошибке выполнение скрипта прекращается.

### `load_vfs(vfs_path)`

Загружает JSON-файл VFS в память и обрабатывает
ошибки загрузки.

### `validate_vfs(vfs)`

Проверяет структуру виртуальной файловой системы.

### `validate_node(node)`

Рекурсивно проверяет файлы и директории внутри VFS.

## Запуск

В Windows приложение можно запустить через:

```powershell
.\run.bat
```

Параметры также можно передавать через `run.bat`:

```powershell
.\run.bat --prompt "shell> "
```

Прямой запуск через Python:

```powershell
python src\main.py
```

## Тестирование

Автоматические тесты запускаются из корня проекта:

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют:

- создание стандартного и пользовательского приглашения;
- разбор параметров командной строки;
- разбор команд;
- команды `ls`, `cd` и `exit`;
- обработку неизвестных команд;
- остановку стартового скрипта при ошибке;
- проверку структуры VFS;
- загрузку корректной VFS;
- обработку некорректного JSON.
