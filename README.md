# Эмулятор командной оболочки

Практическая работа по дисциплине
«Конфигурационное управление».

Вариант №8.

## Описание

Проект представляет собой эмулятор командной оболочки
UNIX-подобной операционной системы.

На первом этапе реализован минимальный REPL-прототип
с консольным интерфейсом.

Приглашение к вводу формируется на основе имени текущего
пользователя и имени компьютера.

Поддерживаются команды:

- `ls` — команда-заглушка;
- `cd` — команда-заглушка;
- `exit` — завершение работы эмулятора.

Также реализована обработка неизвестных команд
и неверных аргументов.
